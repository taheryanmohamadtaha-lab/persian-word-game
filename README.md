# بازی با کلمات

بازی کلمات فارسی برای گوشی و تبلت اندروید، با الهام از بازی نوستالژیک «بازی با کلمات».
ساخته‌شده با Godot 4.3 و GDScript؛ کاملاً آفلاین.

## راهنمای ساخت APK (بدون برنامه‌نویسی)

1. در GitHub یک مخزن (Repository) جدید بساز؛ مثلاً با نام `persian-word-game`.
2. روی «Add file ← Upload files» بزن و **همهٔ محتویات پوشهٔ این پروژه** را بکش و رها کن (پوشه‌های پنهان مثل `.github` هم باید آپلود شوند). سپس Commit کن.
3. به تب **Actions** برو. ساخت خودکار شروع می‌شود (حدود ۵ تا ۱۰ دقیقه).
4. وقتی تیک سبز آمد، روی همان اجرا کلیک کن و از بخش **Artifacts** فایل `word-game-apk` را دانلود کن.
5. فایل `word-game-debug.apk` را به گوشی بفرست و نصب کن (اجازهٔ «نصب از منبع ناشناس» لازم است).

اگر ساخت خطا داد، متن خطا را برای من بفرست تا اصلاحش کنم.

## نسخهٔ Release امضاشده (اختیاری)

در مخزن: Settings ← Secrets and variables ← Actions، این سه Secret را بساز:
`ANDROID_KEYSTORE_BASE64` (فایل keystore با کدگذاری base64)، `ANDROID_KEYSTORE_USER`، `ANDROID_KEYSTORE_PASSWORD`.
با داشتن آن‌ها، Workflow خودش نسخهٔ Release را هم می‌سازد. کلید امضا را هرگز داخل مخزن نگذار.

## ساختار پروژه

- `project.godot`, `export_presets.cfg` — تنظیمات پروژه و خروجی اندروید
- `scenes/main.tscn` — تنها صحنهٔ اصلی؛ صفحه‌ها با کد ساخته می‌شوند
- `scripts/` — منطق بازی (`game_state.gd` وضعیت و ذخیره، `hero.gd` شخصیت، `sfx.gd` صدا)
- `scripts/screens/` — صفحه‌ها: شروع، انتخاب گروه سنی/سطح، نقشه مرحله، بازی، نتیجه، دستاوردها، تنظیمات، راهنما
- `data/questions/` — سؤال‌ها (JSON) و `index.json` فهرست فایل‌ها
- `assets/` — فونت وزیرمتن (مجوز OFL)، صداها و موسیقی تولیدشده با کد
- `tests/` — تست دودی کل بازی و کنترل کیفیت سؤال‌ها
- `.github/workflows/build-apk.yml` — ساخت و تست خودکار

## افزودن سؤال

هر سؤال یک شیء JSON است:

```json
{"id": "k-e-007", "age": "kids", "diff": "easy", "topic": "animals",
 "answer": "خرگوش", "clue": "حیوانی با گوش‌های بلند که هویج دوست دارد",
 "hint": "جست‌وخیز می‌کند", "points": 10}
```

- `age`: `kids` یا `teens` یا `adults` — `diff`: `easy` یا `medium` یا `hard`
- پاسخ فقط از حروف الفبای فارسی باشد (بدون فاصله و نیم‌فاصله) و بین ۲ تا ۱۰ حرف
- هر سه سؤال یک مرحله می‌سازند (ثابت `LEVEL_SIZE` در `game_state.gd`)
- بعد از افزودن، `python3 tests/validate_questions.py` را اجرا کن؛ کنترل کیفیت تکراری‌ها، حرف نامعتبر و لو رفتن پاسخ در سرنخ را می‌گیرد.
- برای بستهٔ جدید، نام فایل را به `data/questions/index.json` اضافه کن.

## وضعیت فعلی (نسخهٔ ۰٫۱)

- **انجام‌شده:** هستهٔ کامل بازی، شخصیت متحرک با ۸ حالت و دیالوگ فارسی، گروه سنی و سطح مستقل، سیستم امتیاز/سکه/ستاره/دستاورد، ذخیرهٔ خودکار، تنظیمات، موسیقی و جلوه‌های صوتی، ساخت خودکار APK.
- **محتوا:** فعلاً ۵۴ سؤال در ۱۸ مرحله (۲ مرحله برای هر ترکیب سن و سطح). رسیدن به ۱۰۰ مرحله فاز بعدی است.
- **صدای گفتاری:** با موتور گفتار خود گوشی کار می‌کند؛ اگر گوشی صدای فارسی نصب نداشته باشد، دیالوگ‌ها فقط به‌صورت متن در حباب دیده می‌شوند.
